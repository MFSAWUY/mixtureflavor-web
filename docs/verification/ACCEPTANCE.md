## 五并发本机性能

原始数据：[performance-local.json](performance-local.json)。Windows 11，本机 28 个逻辑 CPU，模型限制 2 个计算线程，HTTP 并发数为 5。临时后端使用独立数据库，每种情景预热后发起 50 次请求，计时包含 HTTP、校验、推理和 SQLite 保存。

| 情景 | 请求数 | 失败 | 中位数 | P95 | 最大值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 单分子 | 50 | 0 | 87.90 ms | 159.80 ms | 168.25 ms |
| 五组分混合物 | 50 | 0 | 186.83 ms | 245.17 ms | 285.71 ms |

启动至健康约 4.30 秒；测试期间 10 ms 间隔采样的进程峰值 RSS 为 677.14 MiB。这是本机 Windows / CPU 路径结果，PyTorch 安装包含 CUDA 库但推理未使用 GPU；不能直接推定香港 2 核云服务器的并发性能或 Linux CPU 镜像内存占用。
